# 📚 Cloud Guardian Documentation Repository

This directory organizes all architectural specifications, patent disclosures, academic manuscripts, compliance guides, and historical drafts for the Cloud Guardian project.

## 1. Claim-Support & Evidentiary Materials (`docs/support/`)

Technical disclosures, claim charts, and evidentiary mappings supporting patent filings and audits:

- **[`PATENT_DRAFT_INDIA_V2.md`](support/PATENT_DRAFT_INDIA_V2.md)**: Active Indian Patent Office (IPO) Form 2 complete specification defining the Layer 5 runtime constraint compilation, pre-solve certification, and certificate-bound actuation invention.
- **[`PATENT_CORE_CLARIFICATION.md`](support/PATENT_CORE_CLARIFICATION.md)**: Clarification of the inventive core, claim restructuring, technical boundaries, and five-element independent claim chain.
- **[`PATENT_CLAIM_SUPPORT_MATRIX_V2.md`](support/PATENT_CLAIM_SUPPORT_MATRIX_V2.md)**: Element-by-element traceability matrix mapping patent claims to source modules, mathematical functions, test cases, and empirical benchmark experiments.
- **[`PATENT_FIGURE_SPEC_V2.md`](support/PATENT_FIGURE_SPEC_V2.md)**: Formal drawing specifications, functional descriptions, and reference numeral callouts for patent drawings Figures 1 through 7.
- **[`PRIOR_ART_LAYER5_CORE.md`](support/PRIOR_ART_LAYER5_CORE.md)**: Prior art literature and patent search analysis differentiating the Layer 5 architecture from Connectfree, Battelle, Dutta, and related approaches.
- **[`INDEPENDENT_CODE_AUDIT_REFERENCE.md`](support/INDEPENDENT_CODE_AUDIT_REFERENCE.md)**: Independent code audit reference documenting architectural integrity, mathematical soundness, test coverage, and formal verification addenda.
- **[`PATENT_INNOVATION.md`](support/PATENT_INNOVATION.md)**: Technical invention disclosure detailing 12-dimensional comparative differentiation and prior-art rebuttals.
